# veda.ng Research Hub

Use the product MCP server to search 233,000+ academic papers, published research essays, and AI and Web3 glossary definitions.

## Product MCP Server

Connect with Streamable HTTP at `https://veda.ng/.well-known/mcp`.

Available tools include `search_reports`, `search_essays`, `get_essay`, `search_glossary`, and `get_glossary_term`.

## Documentation MCP Server

Connect with Streamable HTTP at `https://veda.ng/.well-known/mcp/docs` to retrieve API documentation, the OpenAPI specification, authentication guidance, and course curricula.
